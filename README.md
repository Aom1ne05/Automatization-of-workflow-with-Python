# Automatization of workflow with Python
## A program for automatization of Secretary's work

"You need to help the secretary automate their work. 
To do this, you need to write a program that will execute user commands based on the stored data.
The initial data has the following structure:

* documents.json contains dictionaries with data of documents: document type, document number, document owner.
* in directories.json stores "shelves" - numbered keys and lists as values that store document numbers
* .exe File stores in 'dist' folder
